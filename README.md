# Climbing Weather App

This repo is a TypeScript implementation of a web app for tracking weather in climbing areas. This would ideally replace my other project, Prime Condies, but more than anything it's a good way for me to learn TypeScript (and dogfood some Copilot products :wink:)

Development plan: 
1. Implement API calling, basic types for climbing areas, and the basic functionality of going from climbing area to forecast results (not doing anything with them)
2. Extend types/interfaces for areas + forecast responses, do something the responses, clean up forecast trajectories, and support multiple selected areas
3. Implement the functionality for a "condition," with the notion of ideal and acceptable ranges
4. Front-end (likely with recharts)
5. Extend climbing dataset
6. Hosting? 
7. Maybe adding an LLM summary to help you decide? 

Anything beyond that feels way too far off :sweat_smile:
